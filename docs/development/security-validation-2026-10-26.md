# Security validation matrix — 2026-10-26

This matrix records repository-side implementation and test evidence for the security review. It does not claim a deployed test. Hosted OAuth broker code and its production secrets are outside this repository; broker endpoint cryptographic behavior and live-provider behavior remain unverified here.

## Execution record

### 2026-10-27 follow-up

- Hosted connector OAuth completion now requires the initiating browser cookie and the exact return origin recorded in the OAuth session. The cookie path covers both `/api/connectors/oauth/callback` and `/api/connectors/oauth/complete`. `ConnectorValidationEndpointTests.HostedConnectorCompletionRequiresTheInitiatingBrowserAndReturnOrigin` verifies that missing-cookie and attacker-origin requests are rejected without consuming the state, while the initiating browser can proceed.
