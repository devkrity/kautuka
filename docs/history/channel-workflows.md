# Historical channel and workflow notes

This note preserves a high-level record of the early channel and workflow implementation. It is not an operations guide; use the current [channel verification guide](../development/channel-verification.md), [Telegram channel UX](../operations/telegram-channel-ux.md), and [workflow documentation](../plans/agent-workflows.md) for current behavior.

The early implementation supported account and agent chat attachments, channel delivery preferences, workflow review cards, and approvals originating from workflow steps. Workflow review and tool approval used distinct pause and resume behavior. These capabilities continued to evolve after the initial alpha cut; historical test identities, installation details, identifiers, and machine-specific observations are intentionally omitted here.
