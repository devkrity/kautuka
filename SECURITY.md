# Security Policy

## Supported Versions

Security fixes are applied to the active development branch and the most recent
release branch, if one exists.

## Reporting A Vulnerability

Do not open public issues for security vulnerabilities.

Report suspected vulnerabilities through GitHub private vulnerability reporting,
or email [security@devkrity.com](mailto:security@devkrity.com). Include:

- A clear description of the issue
- Reproduction steps or proof of concept
- Impact assessment
- Any relevant logs, traces, or screenshots with secrets removed

You can expect an initial response within 5 business days.

## Scope

Please report issues involving:

- Authentication or authorization bypass
- Secret exposure
- Sandbox or container escape risks
- Multi-tenant data isolation failures
- Supply chain compromise or insecure dependency behavior

## Disclosure

After triage and remediation, coordinated disclosure is preferred. Credit will
be given unless you ask to remain anonymous.
