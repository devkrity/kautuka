# Archived Kautuka terminal UI

`Kautuka.Tui` was the legacy Kautuka terminal user interface and `kautuka` CLI.
It has been retired and is retained here only for historical reference. It is
excluded from the active solution, integration test project, installer, and
release pipeline. New releases do not install or update the CLI.

The former integration tests are retained in `tests/` as historical records;
they are not run by the active test suite. This project is not a supported
build target.
