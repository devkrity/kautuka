# Archived Kautuka desktop client experiment

`Kautuka.Control.Core` and `Kautuka.Control.Desktop` are a retired desktop-shell
experiment. They are kept here for historical reference and are not part of the
active `src/Kautuka.slnx`, installer, or release pipeline. Do not use these
projects as the current Windows appliance or tray implementation; that product
uses `Kautuka.Installer.Windows` and `Kautuka.Monitor`.

The project files remain alongside their source, but this archive is not a
supported build target.
