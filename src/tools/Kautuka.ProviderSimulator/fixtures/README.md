# Consumed-protocol fixture corpus

These fixtures are sanitized shapes derived from the linked official provider documentation. They contain no credentials, user content, or reusable provider identifiers. The simulator deliberately implements only these consumed shapes; a new provider call requires a fixture and conformance update.

| Provider | Protocol version | Provenance |
| --- | --- | --- |
| Telegram | Bot API consumed subset | https://core.telegram.org/bots/api |
| Slack | Web API + Socket Mode consumed subset | https://docs.slack.dev/apis/web-api/ and https://docs.slack.dev/apis/socket-mode/ |
