Windows installer

This Windows installer is not Authenticode-signed. SmartScreen will warn.

Setup

Pick the local folder and release channel. A GitHub token is only needed for private GitHub releases.

Folder where WSL should store the imported distro. The appliance is self-contained inside its WSL filesystem; no Windows bind mount is created.

Development profile: point this at the local or LAN release server. The installer will resolve the manifest from this base URL.

Preview builds are for testing new features early and may have bugs.

Off by default. The appliance only listens on localhost. Checking this adds a Windows Firewall rule for TCP 20229 on private networks and forwards that port to localhost. Public networks stay blocked, and the traffic is ordinary HTTP.
